A program that writes exactly one word — the word Grandma would text about AI — to `/output/entry.txt`. Grandma means the clever machine grandchild, types it the way she hears it, and the typo is the whole joke: one warm, baffled, affectionate word.

## Run it

```sh
python3 main.py
```

Pure Python standard library, no dependencies. Writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
